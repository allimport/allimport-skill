# stock-fotos/

Fotos reales de producto (JPEG), para usar como fondo (`.bg-photo`) en el sistema de
stories HTML (`PROMPT DISEÑO SECUENCIAS DE STORIES — ALL IMPORT`).

Poné acá las fotos tal cual las sacás — sin editar. El sistema las recorta, les aplica
el degradado oscuro y les pone el texto encima según el guión que le pases.

Nombrá los archivos de forma descriptiva (ej. `stock-cables-cargadores.jpg`,
`parlantes-jbl.jpg`) para que sea fácil elegir cuál va en cada slide.

Esta carpeta no se sube al repo vacía por accidente porque tiene este README —
las fotos que agregues sí quedan versionadas (son tuyas, del negocio, no hay problema
de privacidad como con Canva).
