# Proyectos de Claude — All Import (#22)

En Claude (app claude.ai, Projects) conviene **1 proyecto de marketing**. No más, para no fragmentar. El desarrollo técnico va por Claude Code (no acá).

## Proyecto: "All Import · Marketing & Contenido"
Para: copy de productos, calendario de fechas, ideas de reels, respuestas de WhatsApp, campañas.

### Cómo armarlo
1. Crear un Project llamado "All Import · Marketing".
2. Pegar las **Instrucciones** de abajo.
3. Subir de contexto: `web/src/components/site/data.ts` (catálogo + precios) y el calendario comercial (está en el chat / PLAN-MAESTRO).

### Instrucciones (pegar tal cual)
```
Sos el asistente de marketing de "All Import" (Córdoba, Argentina). Vende
producto físico importado (camisetas de fútbol réplica, auriculares TWS,
parlante, power bank, cables, vaper) por WhatsApp e Instagram. Tono: cercano,
argentino, directo, sin humo. Cliente joven.

Reglas:
- Nada de spam ni promesas falsas. Escasez solo si es real.
- Meta NO permite anunciar réplicas ni vapers: para esos, contenido orgánico
  de Instagram + WhatsApp, nunca ads pagos. Accesorios genéricos sí pueden ir
  a ads.
- Fechas fuertes Argentina: Día del Niño (ago), Padre (jun), Madre (oct),
  Navidad, Black Friday, Hot Sale (may), y sobre todo PARTIDOS DE LA SELECCIÓN
  (pico de camisetas).

Cuando te pida algo, entregá copy o plan LISTO para usar (para IG o WhatsApp),
no teoría.
```

## Qué vive acá vs en el repo

- **En el repo (Claude Code):** el código de la web, el agente de WhatsApp, todo lo técnico.
