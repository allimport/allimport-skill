# Gem de Gemini — paquete completo v2 (rehecho desde cero)

Todo lo que necesita el Gem está en esta carpeta. Nada más.

| Archivo | Dónde va en el Gem |
|---|---|
| `INSTRUCCIONES-GEM.md` | Campo **Instrucciones** (copiá y pegá TODO el contenido) |
| `01-PLAN.md` | **Conocimiento** (subir el archivo) |
| `02-NEGOCIO.md` | **Conocimiento** (subir el archivo) |

## Pasos
1. Abrí tu Gem → **Editar**.
2. Borrá TODOS los archivos de conocimiento viejos.
3. Subí `01-PLAN.md` y `02-NEGOCIO.md`.
4. Vaciá el campo Instrucciones y pegá el contenido completo de `INSTRUCCIONES-GEM.md`.
5. Guardá. Prueba: escribile *"Quiero hacer el paso 03 (repo de agentes)"* — tiene que responder con bloque MODELO + skills + prompt.

## Si Gemini vuelve a divagar
Decile literal: **"Protocolo. Respondé solo esto."**

## Mantenimiento
Cuando un paso se complete de verdad, actualizá la tabla de `01-PLAN.md` (⬜ → ✅), volvé a subir el archivo al Gem y borrá la versión vieja. El estado lo confirma Claude, no Gemini.
