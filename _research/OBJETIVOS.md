# OBJETIVOS — All Import (antes de producir contenido)

Fijados antes de crear historias/videos/guiones. Todo lo que hagamos sirve a estos 3.

## Objetivo madre
Crecer en redes de forma **semi-automatizada**: vos ponés la cara (grabás videos, sacás
fotos), Claude hace el resto (edita, genera guiones + ejemplos de historias, investiga
qué quiere el mercado y qué es viral). Marca personal `@_agus_moreno_`.

## Modelo de negocio (foco real)
El core es **mayorista / reventa + acompañamiento**: le vendés a gente que quiere
**emprender** (18-28, con algo de ahorro) productos de reventa + tu mentoría ("contás
conmigo para lo que sea"). El contenido atrae emprendedores → el agente los asesora y arma
combos → vos cerrás y acompañás. Ese es el loop. (También hay venta minorista, secundaria.)

## Los 3 objetivos concretos

### O1 · Motor de contenido asistido
- **Vos:** grabás reels a cámara + sacás fotos de producto. (📱)
- **Claude:** edita fotos → historias, genera guiones de reel, ejemplos de historias,
  carruseles; e **investiga viralidad** del nicho (emprender 18-28, Córdoba): qué temas,
  qué formatos, qué ganchos funcionan y *por qué*.
- **Éxito:** cada semana hay 3 guiones listos + tanda de historias + 1 hallazgo de "qué
  está funcionando" — sin que improvises.

### O2 · Agente de WhatsApp (responde + etiqueta + habla como vos)
- Responde consultas en un **horario** definido.
- **Etiqueta** cada chat: compró / potencial / curioso.
- **Habla igual que vos** (perfil de voz — ver `contenido/VOZ-AGUS.md`).
- Pasa a humano (vos) cuando la consulta es compleja.
- **Stack elegido:** n8n + WAHA + Claude + planilla (ver `_research/n8n-whatsapp.md`).
- **Éxito:** un cliente escribe fuera de hora → recibe respuesta correcta con tu tono, y
  queda etiquetado en la planilla.

### O3 · Base de datos de clientes (memoria)
- Un Excel/planilla con **info de cada cliente**: nombre, fecha, producto, monto, pago,
  envío/retiro, teléfono, **etiqueta**, notas.
- La llena el agente (O2) y/o vos.
- **Éxito:** buscás un cliente y ves todo su historial en una fila.

## Regla
Nada de métricas inventadas. Automatizamos lo repetitivo; la cara y la confianza son tuyas.
Foco redes primero; el resto (web, backend) va después.

## Qué necesito de vos para arrancar
1. **5-10 mensajes reales tuyos** de WhatsApp/DM (para armar tu perfil de voz `VOZ-AGUS.md`).
2. **Horario** en que el agente debe responder (ej. 9-22).
3. Confirmar si el agente **cierra ventas** o solo responde + agenda + etiqueta.
