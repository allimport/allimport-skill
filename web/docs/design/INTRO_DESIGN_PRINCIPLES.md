# INTRO DESIGN PRINCIPLES

## Filosofía

La Intro no busca impresionar.

Busca generar confianza.

La sensación debe ser:

- precisión
- silencio
- control
- calidad
- peso físico

Nunca espectáculo.

Nunca sci-fi.

Nunca gaming.

Nunca demo de Three.js.

## El protagonista

El protagonista absoluto es el logo.

No el fondo.

No las partículas.

No el shader.

No la cámara.

No el mouse.

Todo existe únicamente para hacer que el logo se perciba más real.

## La luz

La única fuente emocional de luz es el rayo.

Todo lo demás acompaña.

Si otra luz roba protagonismo, está mal.

## El movimiento

Todo movimiento debe sentirse pesado.

Nunca rápido porque sí.

Nunca elástico.

Nunca flotante.

Debe sentirse como un objeto real.

## El fondo

El fondo existe para generar profundidad.

No debe llamar la atención.

Si alguien recuerda el fondo antes que el logo, el diseño falló.

## El color

El negro domina.

El blanco define.

El cyan solo acentúa.

Nunca competir entre sí.

## Interacción

El usuario no mueve la escena.

Solo influye levemente sobre el logo.

Debe sentirse como una pieza pesada.

No como un objeto pegado al mouse.

## Fluido

El fluido no es humo.

No es agua.

No es fuego.

No es magia.

Es una deformación del vacío.

Debe descubrirse.

Nunca mostrarse.

## Regla de oro

Ante cualquier duda:

Eliminar.

No agregar.

La experiencia mejora cuando sobra menos.
