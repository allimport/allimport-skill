# Funnel Builder

## When to use
- Launching a new product/feature and need a full acquisition-to-retention path
- An existing funnel has a known drop-off stage that needs fixing

## Process
1. **Map the stages**: awareness → acquisition → activation → retention → revenue → referral.
2. **Define the goal metric per stage** — what "success" means at each step (e.g. activation = first key action completed).
3. **Find the biggest leak** — the stage with the largest relative drop-off, not the stage that's easiest to tweak.
4. **Design the fix to match the leak's cause** — confusion → clarify UX/copy; lack of trust → add social proof; lack of urgency → add a deadline/incentive.
5. **Instrument before declaring success** — make sure the stage's metric is actually tracked so the fix's impact is measurable.

## Checklist
- [ ] Each stage has a defined success metric
- [ ] Fix targets the largest actual leak, not a guess
- [ ] Instrumentation in place to measure the fix's effect
