# SERP Analysis

Analyze the search engine results page for a given query to understand:
- SERP composition and features (AI Overview, featured snippets, PAA boxes, image carousels)
- Search intent signals from ranking pages
- Content patterns among top-ranking pages
- Keyword demand and competitive difficulty

## When to Use

- User asks "what does the SERP show?" or "why do pages rank?"
- Analyzing SERP composition before content planning
- Understanding search intent before writing
- Evaluating competitive landscape for a query

## Workflow

1. **Observe** — Identify SERP features present (AI Overview, snippets, images, local pack)
2. **Classify intent** — Informational, navigational, commercial, transactional
3. **Analyze top results** — Content type, format, depth, angle
4. **Identify gaps** — What ranking pages miss that searchers want
5. **Recommend** — Content strategy based on evidence, not guesses

**Important**: Separate observed SERP evidence from keyword demand estimates. Hand off to content planning only after intent and SERP features are clear.
